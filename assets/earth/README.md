# Earth texture provenance

The globe uses NASA Earth Observatory's **December 2004 Blue Marble: Next Generation with Topography and Bathymetry**.

- Source page: https://science.nasa.gov/earth/earth-observatory/blue-marble-next-generation/base-topography-bathymetry/
- Original JPEG: https://assets.science.nasa.gov/content/dam/science/esd/eo/images/bmng/bmng-topography-bathymetry/december/world.topo.bathy.200412.3x21600x10800.jpg
- Original dimensions: 21,600 × 10,800 pixels (about 2 km per pixel)
- Original SHA-256: `3006C58B1272362DB0A8C2DF02DC07CEA4B12DFE820B7DC4A159A075CAF5D4D4`
- Retrieved: 11 August 2026

The browser assets were resized from that original with Pillow 12.2.0 using Lanczos resampling. WebP files use quality 88 and method 6. The JPEG fallback uses quality 90, progressive encoding, optimisation and 4:2:0 chroma subsampling.
