How the library was made

Kept short and honest, because it changes how much you should trust each entry.

The screens came from the Aura prototype. A script found the artwork on each screen and cut it out, duplicates were folded together so a shared icon like the back arrow appears once, and each remaining cut-out was described by a reading pass. Sizes are the original pixel sizes. The "seen on" count tells you how widely an icon was used in the prototype, which is a fair guide to how central it is. Some entries are rough: where a cut-out was unclear the description says so rather than inventing a meaning.
